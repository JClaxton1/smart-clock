Clocks install new versions at night, around 3 AM. To install straight away, press Check for updates now on the clock's Setup tab, or send update to the clock's ntfy command topic.

Install with a USB cable

Only needed the first time, or to repair a clock that won't start. Updates after that arrive over WiFi.

  1. Use Chrome or Edge on a computer (phones and Safari can't do this).
  2. Plug the clock into the computer with a USB-C data cable.
  3. Press the button, pick the port that appears (usually "USB JTAG/serial debug unit"), then Install.
This browser can't talk to USB devices. Please open this page in Chrome or Edge on a computer. Please open this page over https.

When it asks about erasing, leave Erase device unticked: the clock then keeps its WiFi, screen direction, light settings and hand position. If the clock isn't found, hold its BOOT button while plugging it in, then try again.
