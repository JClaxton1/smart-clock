Clock software

The clock checks this page by itself and installs new versions at night. You only need this page to set up a new clock or repair one that won't start.

To install the newest version straight away: on the clock's settings page, open Setup, then Check for updates now.

Install with a USB cable

  1. Use Chrome or Edge on a computer. Phones and Safari can't do this.
  2. Plug the clock into the computer with a USB-C data cable.
  3. Press the button below, pick the port that appears (usually "USB JTAG/serial debug unit"), then Install.
  4. When it asks about erasing, leave Erase device unticked. The clock then keeps its WiFi, screen direction, light settings and hand position.
This browser can't talk to USB devices. Open this page in Chrome or Edge on a computer. This page needs to be opened over https.

If the clock isn't found, hold its BOOT button while plugging it in, then try again.
